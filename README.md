# 书屿 · 书签新标签页

把浏览器收藏夹变成一张干净、好用的起始页：打开新标签页，就能看到按文件夹整理好的书签磁贴，像手机桌面一样拖拽整理，也能随时搜索、换壁纸、调布局。

界面与交互思路借鉴了 **Infinity 新标签页**（磁贴式布局、文件夹弹层、分页翻页、自由布局等）

## 功能简介

### 书签与文件夹
- 自动读取浏览器书签栏，按文件夹分组展示为磁贴；可开关是否合并「其他书签」。
- 文件夹以九宫格缩略图呈现，点开后是居中的文件夹弹窗，支持多级进入与返回。
- 文件夹弹窗的列数、行数可在设置中调整，内容从左到右排列，条目多时自动分页。
- 文件夹内、主页网格都支持拖拽排序；拖到某个书签左/右半边可插到它前面或后面，真实写回浏览器书签顺序。
- 支持把书签拖入文件夹，也支持从文件夹弹层拖出到书签栏。
- 拖拽时有明显提示：跟随光标的气泡、插入位置高亮竖线、文件夹「移入」高亮、拖出时的「松开移出到书签栏」提示。

### 翻页与浏览
- 主页磁贴按行列分页，支持分页按钮、鼠标/触控拖拽翻页，翻页使用 GPU 合成动画，丝滑且不影响点击性能。
- 文件夹弹窗同样支持按钮翻页、滚轮翻页和滑动手势。

### 搜索
- 居中搜索框，可选择/新增/删除搜索引擎。
- 输入时只展示搜索建议（匹配书签与网页搜索入口），不会过滤下方磁贴。
- 支持隐藏搜索框、隐藏搜索类别、隐藏搜索按钮、保留上次搜索内容、调整搜索框大小与垂直位置。

### 个性化
- 时钟与日期、每日一言（可自定义内容），固定显示在左上角。
- 壁纸支持渐变预设、纯色、自定义图片上传，并可调模糊与暗化程度。
- 磁贴可调：行列数、横纵间距、图标大小、圆角、透明度。
- 图标显示模式：网站图标（favicon）或网站名首字，后者更省性能。
- 字体大小、颜色、阴影可调。
- 右上角快捷菜单：历史记录、下载、密码、扩展、收藏夹等系统入口，可逐项开关。
- 书签可设置在新标签页打开还是当前页跳转。
- 配置支持导出，方便备份或迁移。

### 安装与使用
1. 打开 Chrome / Edge 的扩展管理页，开启「开发者模式」。
2. 选择「加载已解压的扩展程序」，指向本项目目录，或直接解压 `shuyu-v1.0.0.zip` 后加载。
3. 扩展会自动接管新标签页；点击扩展图标也可打开。
4. 书签变更会自动同步，无需手动刷新。

## 目录结构

```
manifest.json        扩展清单（MV3）
service-worker.js    点击扩展图标打开新标签页
newtab.html          新标签页结构
css/                 主页面与设置面板样式
js/
  app.js             页面装配与设置应用
  bookmarks.js       书签读取、搜索匹配、真实排序移动
  grid.js            主页磁贴网格、分页、拖拽
  folder-panel.js    文件夹弹窗、分页、拖拽
  search.js          搜索框与建议
  settings-panel.js  设置抽屉
  store.js           配置与壁纸存储
  constants.js       默认配置、预设、系统快捷入口
  util.js            通用工具与拖拽提示
icons/               扩展图标
```

## 说明

- 数据全部保存在本地浏览器（`chrome.storage`），不会上传服务器。
- 「其他书签」等系统文件夹遵循浏览器自身权限，部分内容可能不可编辑，属正常现象。
- 本项目参考了 Infinity 的产品形态与交互，但代码、图标、背景等资源均为独立实现，使用时请遵守各自平台的版权要求。
